The method

Nothing is learned alone.

Each page follows the same chain, so a new concept always arrives as the answer to a problem you already met.

  • 0001

    Problem

    Every topic starts with something that hurts: a failure, a gap, a question nobody could answer.

  • 0002

    Fix

    A concept arrives to solve it. You learn the idea together with the reason it exists.

  • 0003

    New problem

    Every fix leaves a limit. That limit is the doorway to the next week.

  • 0004

    Boss fight

    Test-style questions with model answers lock the chain in place.
